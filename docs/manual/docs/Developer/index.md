# GeoNetwork 5 Developer Documentation

Welcome to the GeoNetwork developer documentation! The purpose of this document is to outline the system architecture of GeoNetwork 5 backend. Its primary objectives are to:

* **Define the System:** Provide a comprehensive overview of the platform’s core features, underlying technology stack, and design patterns.
* **Onboard Technical Staff:** Serve as the foundational entry point for developers and administrators to understand how the system’s components interact.
* **Record Technical Decisions:** Act as a centralized Architecture Decision Record (ADR). Every architectural, functional, and systemic design choice made during development is tracked here to preserve context and rationale.

This document will NOT include the description of any client or UI.
